# /setup — Memplexor bootstrap

You are running the Memplexor `/setup` command in the current project at `$PWD`.

## Arguments

Parse `$ARGUMENTS` (space-separated flags):
- `--dry-run` → analyze + report only, write nothing
- `--refresh` → re-run analysis, refresh generated files only
- `--force` → overwrite generated files even if they lack the generation marker; never delete user memory
- `--preserve-memory` → default; preserve CURRENT.md, HISTORY.md, sessions/*
- `--help` → print this usage and exit

If `--help`: print the argument list above and stop.

## Step 1 — Detect project root

`project_root` is the current working directory (`$PWD`). Never write outside it.

## Step 2 — Inspect repository

Read whichever of these exist (use `Glob`/`Read`; never assume):

| File | Signal |
|---|---|
| `package.json` | Node + scripts + framework deps |
| `pnpm-lock.yaml` / `yarn.lock` / `package-lock.json` / `bun.lockb` | Package manager |
| `pyproject.toml` / `requirements.txt` / `Pipfile` / `poetry.lock` | Python |
| `Cargo.toml` | Rust |
| `go.mod` | Go |
| `Gemfile` | Ruby |
| `composer.json` | PHP |
| `Makefile` | Build commands |
| `tsconfig.json` / `.eslintrc*` / `.prettierrc*` / `ruff.toml` | Style/typecheck |
| `Dockerfile` / `docker-compose.yml` | Containers |
| `.github/workflows/*` / `.gitlab-ci.yml` | CI |
| `README.md` | High-level description |

Detect:
- Primary language(s)
- Framework(s) (Next.js, React, FastAPI, Django, Rails, Axum, Gin, …)
- Package manager
- Build / Test / Lint / Typecheck / Run commands (from scripts section or Makefile)
- Key top-level directories (`src/`, `app/`, `lib/`, `tests/`, `pkg/`, etc.)

## Step 3 — Plan changes

Compute the file list. **THESE ARE THE ONLY PATHS YOU WRITE.** Do not create
`.claude/memory/CURRENT.md` or `.claude/memory/HISTORY.md` at the memory root —
those go inside `context/` and `progress/`.

```
.claude/memory/                                (mkdir -p)
.claude/memory/context/                        (mkdir -p)
.claude/memory/progress/                       (mkdir -p)
.claude/memory/sessions/                       (mkdir -p)
.claude/memory/context/CURRENT.md              (seed if absent unless --force)
.claude/memory/progress/HISTORY.md             (append setup entry; create if absent)
.claude/skills/project-guidelines/SKILL.md     (generate or refresh)
```

Forbidden paths (never create these):

- `.claude/memory/CURRENT.md`  — wrong, use `context/CURRENT.md`
- `.claude/memory/HISTORY.md`  — wrong, use `progress/HISTORY.md`
- Anything outside `$PWD`

If `--dry-run`: print the plan, exit. Do not write.

## Step 4 — Idempotency rules

- **Generation marker:** include `<!-- Generated by Memplexor -->` in the first line of every generated file
- **CURRENT.md:**
  - Absent → seed from template (Step 5)
  - Present + has marker → refresh if `--refresh` or `--force`, else preserve
  - Present + no marker → preserve unless `--force`
- **HISTORY.md:** always append. Skip the append if the latest H2 entry already matches the new title within 60 seconds.
- **SKILL.md:** treat like CURRENT.md.
- **sessions/**: never touch existing files.

## Step 5 — Write files

Use atomic writes (write to `.tmp.<rand>` then rename) for any file you overwrite.

resolves and the script files exist. Report status.

## Safety rules

- Never delete files.
- Never write secrets (.env, credentials, tokens) into memory.
- Never store full transcripts.
- Stay inside `$PWD` — no parent traversal.
