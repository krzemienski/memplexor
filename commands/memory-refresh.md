# /memory-refresh — re-analyze + refresh

Re-run Memplexor project analysis and update generated files.

## Arguments

- `--skill` → refresh only `.claude/skills/project-guidelines/SKILL.md`
- `--context` → refresh only generated sections of `.claude/memory/context/CURRENT.md`
- `--hooks` → verify/repair hook registration only
- `--all` → all three (default if no scope flag)
- `--dry-run` → print plan, write nothing
- `--force` → refresh even files missing the `Generated by Memplexor` marker
- `--help` → print usage + exit

If no scope flag given, behave as `--all`.

## Step 1 — Re-analyze

Same detection step as `/setup` (Step 2): inspect manifests + configs, derive
stack, commands, key directories.

Diff against existing values where possible:
- Read first 30 lines of CURRENT.md → existing stack summary
- Read SKILL.md → existing build/test/lint commands

## Step 2 — Refresh SKILL.md (if --skill or --all)

- Must already exist; else warn "run /setup first" and skip.
- Verify it has the `<!-- Generated by Memplexor -->` marker.
  - If marker present → safe to rewrite atomically with current analysis.
  - If marker absent → skip unless `--force`.
- Rewrite via tmp + rename.

## Step 3 — Refresh CURRENT.md generated sections (if --context or --all)

Sections eligible for refresh:
- `## Where We Are`
- `## Recent Work`
- `## Next Steps`
- `## Important Files`
- `**Last updated:**` line

Sections **always preserved**:
- `## Open Questions`
- `## Warnings or Constraints`
- Any custom user H2 sections not in the generated list

Strategy: parse existing CURRENT.md into a section map, replace only the
generated sections, keep everything else verbatim. Atomic write.

## Step 4 — Hook verification (if --hooks or --all)

- Confirm `${CLAUDE_PLUGIN_ROOT}/hooks/hooks.json` exists and is valid JSON.
- Confirm `session-start.sh` and `session-save.sh` are executable.
- If something is wrong, report it — do not auto-modify plugin files.

## Step 5 — Append HISTORY.md entry

```markdown

## <ISO-8601> — memory refresh

* Refreshed: <skill | context | hooks | all>
* Detected stack: <stack>
* Notable changes: <e.g. "new test command: pytest -q">
```

Skip the append if the previous H2 entry already says "memory refresh" within
the last 60 seconds.

## Step 6 — Report

```
Refreshed:
* <files>

Preserved:
* <files / sections>

Warnings:
* <e.g. no test command detected>

Verified:
* Hook registration: OK | needs attention
```

If `--dry-run`: show what *would* change with diffs; write nothing.

## Safety

- Atomic rewrites only.
- HISTORY.md is append-only.
- Never delete files.
- Stay inside `$PWD`.
